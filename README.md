# AgroSense – Smart Farm Monitoring System

AgroSense is an IoT-powered smart farm monitoring system designed to help farmers track key environmental conditions in real-time, including soil moisture, temperature, humidity, and sunlight. 

Using affordable sensors connected to an ESP32 microcontroller, AgroSense collects data from the field and sends it to a responsive web dashboard built with HTML, CSS, JavaScript, PHP, and MySQL. Farmers can view live statistics, receive alerts when conditions fall below optimal levels, and make informed decisions about irrigation and crop management.

AgroSense is open-source, scalable, and designed to bring accessible smart farming solutions to farmers around the world.
